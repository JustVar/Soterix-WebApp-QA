# The shared QA pipeline: the QA Touch client, the result reporter, the Jira
# layer and the CI gates. `plugins/` and `tools/` here are thin shims over it,
# so without it pytest cannot even collect.
#
# The package is a wheel file under vendor/, so `pip install -r requirements.txt`
# is the ONLY setup step. It needs no GitHub grant and no CI secret. pip
# resolves the `--find-links` path relative to this file, so the command works
# from any folder when you name this file by path.
#
# Pinned to one version, because a run's results are only comparable if
# everyone is on the same pipeline. tests/plugins/test_shared_package_pin.py
# fails if the installed version, this line and the wheel in vendor/ disagree.
#
# UPDATING THE PACKAGE: in the package repo, bump the version in
# pyproject.toml, push, wait for its CI, tag vX.Y.Z, then build the wheel:
#     python -m build --wheel
# Copy dist/soterix_qa_shared-X.Y.Z-py3-none-any.whl into vendor/, delete the
# old wheel, change the version below, reinstall, run the offline suites, commit.
#
# CHANGING THE PACKAGE: clone it beside this repo and install it editable,
# which overrides the pin until you reinstall:
#     git clone https://github.com/Soterix-Systems/SOTERIX-QA-SHARED.git ../soterix-qa-shared
#     pip install -e ../soterix-qa-shared
--find-links vendor
soterix-qa-shared==0.38.0
