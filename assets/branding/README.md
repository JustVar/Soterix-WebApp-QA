# Branding for the test reports

Two files, fixed names. Replace them to change the logo everywhere at once.

| File | Used for |
|------|----------|
| `logo-wide.png` | The header of run.html, health.html, and the archive index |
| `logo-square.png` | The browser tab icon of those pages |

Any PNG works; keep the square one square. The reports embed both files at
build time, so an already-generated report keeps the logo it was built with.
