# docs/archive

Historical planning, session, and migration documents preserved for reference.
None of these reflect current behavior or active workflows - see the top-level
`README.md` and `AGENTS.md` for the live state.

## What's here

| Category | Files |
|---|---|
| Pilot-era roadmaps | `IMPLEMENTATION_ROADMAP.md` (+ `_root` duplicate), `ANALYSIS_SCREENSHOTS.md`, `migration.md` |
| Session continuity notes | `SESSION_SUMMARY_2025-01-{24,26,27,28}.md`, `TODO_NEXT_SESSION.md` |
| QA Touch onboarding/migration | `QA_TOUCH_COMPARISON_GUIDE.md`, `QA_TOUCH_IMPORT_PLAN.md`, `QATOUCH_API_INTEGRATION_PLAN.md` |
| Selenium migration | `SELENIUM_TO_PLAYWRIGHT_MIGRATION.md` (44 KB log - migration complete) |
| Out-of-scope plans | `MAC_JUSTIFICATION_FOR_IOS_TESTING.md`, `RECAPTCHA_BYPASS_PLAN.md` |

## When to look in here

- Tracing why a decision was made historically (e.g. why we adopted QA Touch).
- Replaying the migration path if a new team takes over and needs the original context.
- Otherwise, ignore - these are frozen in time.
