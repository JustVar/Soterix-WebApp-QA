These documents are provided by the Hardware PM team and describe the NexaiQ edge box platform.

## Hardware Components

Based on these docs, key testable components include:
- Edge boxes (Ubuntu-based)
- GPU configurations (A-100, A-1000, A-4000)
- ZFS RAID storage
- Docker containers
- Network connectivity
- Camera integrations (Hanwha, i-Pro, Avigilon, Vivotek, Axis, VCA)
